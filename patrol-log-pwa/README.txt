IMPORTANT:
Host this folder on HTTPS. GPS/geolocation generally requires a secure context and user permission.
The reverse-geocoding lookup in this prototype uses OpenStreetMap Nominatim. For production/department use, replace it with an approved geocoding/backend service and complete security/CJIS review.

TEST DATA ONLY until your department approves the system and its storage/security architecture.
